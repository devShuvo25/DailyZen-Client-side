# 🕒 DailyZone – Habit Tracker & Motivation App

DailyZone is a modern, responsive web app designed to help users build better habits, stay motivated, and track daily progress.  
Start your journey toward consistency — one habit at a time!  

🔗 **Live Demo:** https://dailyzone.netlify.app

---

## 🚀 Features

- ✅ **Public & Private Habits** – Explore habits shared by others or create your own personal ones.  
- 🔍 **Dynamic Search & Filtering** – Instantly find habits by title or category with real-time updates.  
- 📅 **Progress Tracking** – Visual progress bars and streak badges to keep you motivated.  
- 🧠 **Motivational Insights** – Inspirational quotes and public habits to encourage consistency.  
- 🧭 **Responsive Design** – Fully optimized for desktop, tablet, and mobile devices.  

---

## 🧩 Tech Stack

- **Frontend:** React.js (Vite)  
- **Styling:** Tailwind CSS  
- **Routing:** React Router  
- **Backend:** Express.js + MongoDB  
- **Authentication:** Firebase  
- **Hosting:** Netlify (frontend)
